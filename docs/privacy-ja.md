# プライバシーポリシー - Euro Inline

[Deutsch](/euro-inline/privacy/) | [English](/euro-inline/privacy/en/) | [Français](/euro-inline/privacy/fr/) | [Español](/euro-inline/privacy/es/) | **日本語**

Euro Inline は、ウェブサイト上の通貨金額を検出し、換算後の価格をページ上に直接表示するために、表示されているウェブサイトの内容をブラウザ内でローカルに処理します。

ウェブサイトの内容、商品名、価格は開発者に送信されず、恒久的に保存されることもありません。Euro Inline は閲覧履歴や個人情報を収集しません。

為替レートの計算には Frankfurter API を使用します。その際に送信されるのは、JPY や EUR など、必要な換算元通貨と換算先通貨のみです。

拡張機能の設定とキャッシュされた為替レートは、ブラウザ内にローカル保存されます。

Euro Inline は分析、トラッキング、広告サービスを使用せず、ユーザーデータを販売しません。
